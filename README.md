# Verbolandia 

Aplicación móvil para Android diseñada para facilitar el aprendizaje y la traducción rápida de verbos entre inglés y español.

## Características
* **Traducción On-device:** Integración directa con los modelos de lenguaje locales para traducir verbos al instante.
* **Interfaz Nativa:** Experiencia de usuario fluida y diseñada específicamente para el ecosistema Android.

## Tecnologías y Herramientas
* **Lenguaje:** Kotlin
* **Entorno de Desarrollo:** Android Studio
* **SDK Mínimo:** API 24 (Android 7.0)
* **Procesamiento de Lenguaje:** Google ML Kit Translate
